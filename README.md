# Brain Cancer MRI Classification using Deep Learning

This repository contains a PyTorch-based deep learning pipeline for classifying brain MRI scans into tumor categories or healthy tissue using transfer learning.

## Project Structure
* `main.py`: Core execution script for data pipeline, model training, and evaluation.
* `requirements.txt`: Python package dependencies.
* `data/`: Folder to place your dataset scans (excluded via `.gitignore`).

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd brain-cancer-mri-classification
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the model:**
   ```bash
   python main.py
   ```

## Disclaimer
This project is for educational purposes only and should not be used for medical diagnosis.
